# spidiboost.SpidiBan

Автор: **SpidiBoost**. Minecraft **1.21.4**, Fabric, Java 21, Fabric API.

`/sb delay 5.10` и `/sb delay 10,01` задают обычные десятичные секунды; настройка сохраняется в `config/sbb.cfg`. Все алиасы поддерживаются. В `accept` и `cheats` меню следующего игрока и причина открываются сразу после закрытия предыдущего окна. Два клика «ВЫДАТЬ БАН» выполняются не раньше чем через задержку + 0,01 секунды от предыдущего подтверждения, на ближайшем клиентском тике. Первый бан не ждёт задержку.

Установка: `SpidiBan-1.21.4-<версия>.jar` в `mods` нужного инстанса.

Автообновление проверяется при запуске клиента и подключении к серверу или локальному миру. Обновлятор отображает только установленные LittlePet, SpidiBan, 6ubaaFP и SpidiCard в одном окне; загружает подходящие релизы из SpidiBoostMods, сверяет SHA-256 и метаданные, сохраняет результаты и перезапускает игру один раз. JAR заменяются только после выхода игрового процесса. Резервные копии: `.spidiboost-updates/backups` текущего инстанса. Если надёжно воспроизвести запуск лаунчера нельзя, обновления устанавливаются после обычного выхода; запускать игру нужно через лаунчер.

GitHub недоступен — мод продолжает работать с установленной версией. Обновление одного мода не затрагивает конфигурации, миры или другие моды.

Релизы: https://github.com/SpidiBoostMods/SpidiBan/releases/latest

Сборка: `./gradlew check build` (Java 21). Выпуск: тег `v<mod_version>`, автоматические проверки на Windows/macOS/Linux и публикация JAR, проекта с исходниками и manifest.

SpidiBan полностью включает Hist: `/sb`, `/spidiban`, `/spidiboost`; `accept`, `cheats`, `stop`, `cancel`, `delay`; `shist <ник> <ban|mute> [1–10000]`, `shist status/cancel/retry`, `shist speed <1–1000>`. `stop` и `cancel` останавливают обе очереди, включая `/sb shist`, с сохранением промежуточных результатов. История, решения, незавершённые проверки и результаты остаются в `spidiban-shist` текущего инстанса. Отдельный SpidiBan-Shist-Addon удаляется с резервной копией при автоматической миграции; при первой ручной установке оставьте только объединённый SpidiBan.

В 1.1.1 видимый чат автоматически очищается после каждых 20 уникальных записей `/shist` и каждых 20 завершённых ответов `/checkban` или `/checkmute` (включая таймауты). Ники, очередь, файлы диагностики и история введённых команд сохраняются; очистка не отключает логирование Minecraft и сторонние моды чата. Очищение выполняется на клиентском тике, вне сетевого разбора.

При сборе банов голубой/AQUA текст причины и близкие светлые RGB-оттенки исключаются независимо от формулировки. Цвет времени, метки «Причина» и других полей не влияет. Токены `fp` и `fp_rw` исключаются без учёта регистра, но `FunPay`/`playerok` и случайные подстроки никнеймов не исключаются новым правилом. Проверки мьютов сохраняют прежние правила. Все проверки остаются последовательными, без залпов.

Нативная изолированная проверка: `./gradlew build runVerification -PshistNative` (Java 21). Тестовый клиент работает на титульном экране, использует синтетические ответы и не отправляет команды на сервер. Fixture не включён в production JAR.
